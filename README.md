# Terapia2 · actualizaciones

Este repositorio solo contiene la app Terapia2 ya armada, para que se actualice desde el teléfono con el botón **Actualizar**. El código fuente es privado.

- `vinculo/version.json`: número de la última versión.
- `vinculo/web.zip`: actualización que la app instala sola.
- `vinculo/vinculo.apk`: instalador completo para Android ([descargar](https://github.com/aaroncontrerasfarah/vinculo-actualizaciones/raw/main/vinculo/vinculo.apk)).
